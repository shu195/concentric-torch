Curvilinear CPU Sandbox - every ALU bit is a dot product of a 66-number array; every opcode is decoded by a 23x8 array. No boolean gates in the datapath.

Program

8-bit, 4 regs R0-R3, 256B RAM. Ops: LOAD_IMM LOAD STORE ADD SUB AND OR XOR SLT SHL SHR BEQ BNE JUMP HALT NOP. Display = RAM 0xC0-0xFF.

Neural ALU: raw analog output per bit (threshold 0.5)

CPU state

8x8 display (memory-mapped)
